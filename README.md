# Hackathon

Predicting the selling price of used car, based on the given car features.
The data is scrapped from the cars24.com
(Dependent Variable: Price)

The code contains the following steps:
1. Business Problem Understanding
2. Data Understanding
3. Data preprocessing
4. Modelling
5. Evaluation
6. Model selection

Models applied:
1. Linear Regression
2. Lasso Regression
3. Ridge Regression
4. ElasticNet Regression
5. polynomial Regression
6. KNN Regression
7. SVM Regression
8. Decision Tree Regression
9. Random Forest Regression
10. AdaBoost Regression
11. GradientBoost Regression
12. Artificial Neural Networks
